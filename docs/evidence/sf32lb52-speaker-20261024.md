# Speaker bring-up, 2026-10-24

The installed Home-fixed firmware has CONFIG_AUDIO disabled; NSH has no playback command and /dev/audio is absent. These observations do not test the speaker electrically or acoustically.

The vendor tree includes bf0_hal_audcodec_m.c, but no board audio lower-half registration was found. Added an explicitly invoked, bounded `speaker_test` HAL diagnostic, not an openvela audio driver. It uses DAC channel 0, 48 MHz XTAL / 48 kHz configuration, a low-amplitude 1 kHz triangle waveform, DMA1 channel 8 (refuses if enabled), cache cleaning, and PA10 amplifier enable; stops after one second and disables PA/DMA/DAC. No boot-time automatic playback.

Clock and analog sequencing reference: https://github.com/OpenSiFli/SiFli-SDK/blob/main/rtos/rtthread/bsp/sifli/drivers/drv_audcodec_m.c
Board wiring reference: https://wiki.sifli.com/board/sf32lb52x/SF32LB52-DevKit-LCD.html

CMake diagnostic registration is captured in patches/board/speaker-test-cmake.patch (apply from vendor/sifli root). Diagnostic C source is in app/focusmate/diagnostics/speaker_test.c. It bypasses CONFIG_AUDIO specifically for initial hardware diagnosis; full PCM playback integration still requires an openvela audio lower-half driver and audio subsystem configuration.

Build succeeded. Binary SHA256: cf17551619c6756ea9483210e97b7769b73ffa39d07575f8c00e52f5e8f9b1d0. Flash and physical audibility results pending.

Windows flash and verify completed with exit code 0. NSH speaker_test returned init=0 and stopped result=0; DMA remaining changed 464 -> 412. User explicitly confirmed a clear audible tone. Hardware output chain is accepted for this diagnostic, not full PCM/voice playback. UI process remained alive afterward.

The first test emitted unexpected IRQ 73 (DMA1 channel 8); source now disables HAL refill interrupt sources before enabling DAC consumption, since the immutable circular waveform needs no ISR. This follow-up is build-verified only; installed diagnostic binary remains cf1755... and is not a production audio driver.
